### 🚀 Sobre mí

Desarrollador **Full Stack** enfocado en crear aplicaciones web robustas, escalables y altamente eficientes. Mi especialidad radica en la integración de lógica de negocio potente en el backend usando **PHP y Laravel**, acoplada con interfaces dinámicas, modernas y responsivas con **React, TypeScript y Tailwind CSS**.

Disfruto escribir código limpio (SOLID), optimizar consultas de bases de datos y diseñar arquitecturas de software que garanticen un mantenimiento sencillo a largo plazo.

* 💼 **Actualidad:** Desarrollando sistemas de gestión empresarial, integrando APIs REST y optimizando el rendimiento de datos.
* 🧠 **Especialización actual:** Profundizando en Arquitectura Hexagonal, contenedores con Docker y automatización con CI/CD.
* ⚡ **Filosofía:** Crear software de alta calidad enfocado en aportar valor real y resolver problemas reales.
